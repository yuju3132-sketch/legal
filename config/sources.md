# Source Registry

기관 홈페이지 후보 목록입니다. 등록은 검증 완료를 뜻하지 않습니다. 실제 사용 전 공식 페이지·robots·현재 피드와 날짜를 확인합니다. source verification_status와 errors에 검증결과를 저장합니다. JSON은 실행용 레지스트리, 이 문서는 정책입니다. 자동 수집은 RSS/Atom adapter이며 일반 웹 전체 크롤러가 아닙니다. 활성 피드는 BIS, FSB, Federal Reserve, FCA이며 실패 시 추측으로 채우지 않습니다. 한국·일본 및 나머지 출처는 원문 확인 후 수동 등록 또는 피드 연결이 필요합니다.

Tier 0 국제기준/국제기구; Tier 1 판결·법령·정부/감독기관; Tier 2 공식 Enforcement/Consultation/Guidance; Tier 3 학술; Tier 4 전문기관 분석; Tier 5 뉴스. 중요한 결론은 Tier 0~3 근거로 작성합니다.

필수 모니터링: FATF Recommendations/Guidance/Mutual Evaluation/BO/CPF/Virtual Assets; BIS Governance/Compliance/Capital/Liquidity; KoFIU STR/CTR/CDD/KYC/AML 제재; FinCEN CDD/BO/SAR/CTA/Advisories/Enforcement; OFAC Programs/SDN/Licenses/FAQs/Ownership/Settlements; FCA Handbook SYSC/SUP/DEPP/ENFG/FCG/FCTR/COBS; Japan FSA AML/CFT/FAQ/감독지침/검사/제재. SEC Rules/Proposed/Final/Enforcement/Litigation/Administrative/Guidance/Speeches.

한국법: 상법, 은행법, 자본시장법, 금융사지배구조법, 금융소비자보호법, 특정금융정보법, 외국환거래법, 채무자회생법. 국회 법률안·검토/심사보고서를 원문 확인합니다. 학술지는 기관 repository를 우선하며 일본 영어번역은 현행 일본어 법령과 대조합니다.
